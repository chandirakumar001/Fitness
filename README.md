# 💪 Fitness Freak



A modern fitness website designed to help users improve their fitness through workouts, nutrition guidance, calorie calculation, calisthenics training, and workout music.



## 🚀 Features



- 🏋️ Workout Guides

- 🎯 Fitness Goal Selection

- 🤸 Calisthenics Progression

- 🍎 Food & Nutrition Database

- 🔥 Calorie Calculator

- 🎵 Workout Music Playlist

- ⏮️ Previous / ▶️ Play / ⏭️ Next Controls

- 📊 Music Progress Bar

- ❓ Fitness FAQ Section

- 📱 Responsive Design
